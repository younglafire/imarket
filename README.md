# iMarket

A static website for iMarket - Your Online Marketplace.

## Overview

This is a static website starter pack designed to be hosted on GitHub Pages. It includes:

- **index.html** - Main entry point with responsive design
- **css/style.css** - Modern CSS styling with responsive breakpoints
- **js/main.js** - Basic JavaScript for interactivity

## Features

- Responsive design that works on desktop and mobile
- Smooth scroll navigation
- Modern gradient hero section
- Service cards with hover effects
- Fixed navigation bar with scroll effects

## Hosting on GitHub Pages

1. Go to your repository settings
2. Navigate to "Pages" section
3. Under "Source", select your branch (e.g., `main`)
4. Select the root folder (`/`)
5. Click Save

Your site will be available at: `https://<username>.github.io/imarket/`
